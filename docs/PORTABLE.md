# Windows 便携包

把完整 ZIP 发给朋友，朋友解压整个文件夹后双击启动。不需要安装 Node、npm 或 Steam；使用电脑已有的 Edge / Chrome。目标平台为 Windows 10/11 x64。

| 入口 | 用途 |
| --- | --- |
| 开始游戏-在线联机.cmd | 本机读取所有资源，通过 `wss://cs2.duskrain.cn/ws` 连接公网对局 |
| 开始游戏-离线机器人.cmd | 在本机启动权威游戏服务器，可断网与机器人对战 |
| 校验文件.cmd | 按包内清单校验全部文件的大小与 SHA-256 |

在线联机时，一人创建房间，朋友用自己的本地包输入相同房间码。双方合计 10 个席位；房主可以在空位添加人机。邀请链接仍使用公网游戏地址，供网页玩家加入。本地包用户用房间码加入可直接使用本机资源。

离线房间仅属于当前电脑，不能用离线房间码邀请异地朋友。离线模式点击邀请按钮会说明应改用在线入口。

## 包含内容

- 当前资源锁清单中的 1024 项资源，包括地图、枪械、探员、手臂、皮肤、声音及可选音乐盒。
- 编译后的客户端、机器人服务器、纯 JavaScript 生产依赖。
- Node.js v22.23.2 的 Windows x64 运行程序和许可；来自官方 ZIP，并与官方 SHA-256 清单核对。
- 中文使用说明、素材来源、第三方许可和逐文件校验清单。

首次加载仍需要读取资源、校验并建立 3D 场景，进度条表示本机加载。游戏设置保存在当前浏览器；便携包不携带制作者的昵称或浏览器设置。在线和离线入口使用不同的本机端口，因此两者设置分别保存。

游戏期间保留启动窗口，结束后关闭浏览器和启动窗口即可。文件夹可以整体移动或复制；不需要管理员权限。浏览器仍承担渲染，本包不承诺提升帧率。

## 构建与边界

```sh
npm run build
node scripts/build-asset-lock.mjs
python deploy/package-portable.py
```

输出位于 `artifacts/portable/`，旁边生成 ZIP 的 SHA-256 文本。运行程序只监听 `127.0.0.1`；普通静态服务仅能读取包内 `dist`。启动时端口被同一份包占用会复用已有入口，被无关程序占用则换端口，不关闭其他程序。

压缩包通过允许列表组装，不包含部署脚本、服务器凭据、Git 元数据或个人浏览器资料。在线入口固定连接既有服务器；不会重启或更新公网服务。本包不自动升级，后续不兼容版本需要重新获取客户端包。
