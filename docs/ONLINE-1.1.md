# 在线版 1.1.0

本次将离线 0.2.0 的人机和触控改进同步到网页版、Android 在线包与 Windows 本地联机包。纯离线分支与发布包独立保留。

## 人机与联机边界

- `bot-posts` 检查守点可站立性、视线、路线和占位；`spawn-selection` 分开分配出生位置。
- `bot-alerts` 根据真实目击、听觉和队友事件调度回防，连续报告不会反复延后首轮响应。
- 混合队伍只给有有效守点角色的自动人机分配留守；真人与被接管人机按实际位置计入附近支援。被玩家控制的人机不接受自动回防命令。
- 投掷限制绕路和准备距离；携包者要求时间充足、附近队友持枪保护。既有经济、捡枪、peek、视觉瞄准和平滑转向保留。
- 轻松 / 普通 / 困难默认普通；只有房主能更改房间难度。普通和困难连输两回合增强一次 50%，连赢两回合恢复；轻松不额外增强。
- 命中、回合、经济和人机仍由服务器计算。内部战术不加入对手快照。

## 操作与设置

「设置 → 触屏 → 自定义按键布局」可拖动、缩放、调整透明度，复制或导入布局代码。按钮最小触控范围 44 CSS 像素，横竖屏变化时重新约束在屏幕内。

「设置 → 画面 → 帧率上限」提供不限、30、60、90、120。手机默认 60、桌面默认不限；刷新率和设备性能决定实际可达帧率。帧率门控只跳过画面绘制，客户端固定步长移动与输入发送在门控之前独立处理，服务器 30 Hz、快照 15 Hz 不变。浏览器隐藏页面会停止正常渲染与预测，清除按键并发送取消投掷；在线对局不会暂停，恢复后使用服务器快照。

布局和帧率包含在「本地资源」设置备份内。安卓沿用 `cn.duskrain.dustii` 和原发布签名，素材通过同一 HTTPS 域下的 `/__installed__/` 读取，不改变原设置的存储域，因此无需跨域复制旧设置。升级前仍可主动导出备份。

## 资源与兼容

- `bundledAssets` 只决定素材来源；`mode` 和 WebSocket 地址决定对局在哪运行，两者分开。
- Android 安装包包含桌面 / 手机基础清单、默认装备和声音，约 332 MiB，合计 1,500 个条目。可选皮肤、刀型、音乐沿用按需下载。
- Windows 保留此前完整素材和离线练习入口，联机客户端直接读取本地文件。
- 新客户端和服务器交换规则版本与资源版本；明确不匹配时提示更新。历史客户端缺少版本字段时暂兼容现有协议。
- 网页继续使用原有哈希缓存。安装包中的已有素材不再复制一份到 CacheStorage；新增可选资源仍校验哈希后缓存。
- Android APK 和 Windows ZIP 放在 GitHub Releases，避免大型安装包下载占用 5 Mbps 游戏服务器出口。

## 构建

先 `npm ci`、`npm run assets:fetch`、`npm run build`。

Android：`node scripts/prepare-installed.mjs` 后运行 `scripts/build-android.ps1`。需要 Android SDK、Java 21、Gradle 8.11.1 和原有在线发布密钥；首次构建才初始化密钥，后续不能更换。密钥不会进入仓库。

Windows：`python deploy/package-portable.py`；构建会校验官方 Node 运行时和所有锁定素材，生成文件清单与 SHA-256。

可设置 `DUSTII_BUILD_ROOT` 将 Android 构建输出和 Windows 包输出放到空间充足的磁盘。`dist` 与安装素材临时目录仍由网页构建及素材准备步骤管理。

## 验证和限制

见[验证记录](validation/online-v1.1.0.md)。安装包读取本地素材主要减少下载压力，不能代替网络优化。未据此承诺 P60 帧率、消除所有尖峰，或认定生产服务器必须升级 CPU。
