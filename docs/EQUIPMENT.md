# 装备系统与资料核验

核验日期：2026-09-09。当前包含 23 支枪械、爪子刀、护甲、头盔、CT 拆弹器，以及高爆、闪光、烟雾三类可用道具。CT / T 各 15 支枪，清单按用户截图配置；这里的阵营限制指本项目已配置的携带清单。

本次发布的新主地址：[cs2.duskrain.cn](https://cs2.duskrain.cn/)。迁移后公网验证状态见[稳定性说明](STABILITY.md)。

## 默认搭配与加载

每把枪默认一款支持崭新出厂的皮肤，爪子刀默认为多普勒蓝宝石。共 37 款武器外观：24 款默认崭新皮肤、13 款可选皮肤。24 套默认武器模型按装备加载，不需要一次性预下载全部外观。已下载资源通过网站缓存复用；模型缓存设有容量限制，避免切枪后无限保留显存资源。

双方第一人称手套为运动手套「树篱迷宫」，使用允许的最低磨损 **0.060（崭新出厂）**；归一化附加磨损为 0。原模型、图案、遮罩和材质参数经网页 PBR 烘焙呈现，属于 Source 2 复合材质的近似，不是 Steam 实际物品的浮点或种子复刻。

默认画质最低，视频设置可调整画质与 **60%–160% 亮度**。

## 操作与实现边界

B 打开购买面板，1 / 2 / 3 选择主武器 / 手枪 / 刀，4 循环选择已携带投掷物，左键投掷；Q 切回上一件装备，滚轮上下切换。所有已实现动作可重新绑定。护甲和拆弹器无需手持选择；安装与拆弹继续使用 E。

霰弹枪一次扣动扳机消耗一发，逐颗判定弹丸，按受害者合并命中反馈；管式弹仓逐发装填，装有子弹时可开枪打断换弹。当前 CS2 弹匣式换弹会丢弃旧弹匣余弹，本项目在完成换弹时执行该规则。

道具是第一版原型：服务器维护轨迹、弹跳、引信、伤害和遮挡；烟雾使用半径 4.5 米、持续 18 秒的球形区域阻挡机器人视线，客户端以云片和进入烟雾时的屏幕遮罩呈现。尚无 Source 2 响应式体积烟雾、子弹吹散烟雾、燃烧弹、诱饵弹、低抛、丢枪或退款。每个房间同时最多 40 个飞行投掷物和 40 团烟雾，避免无限积累。

## 同步协议与验证

输入新增 `utilityId` 与 `zoomLevel`；服务器限制其取值并按持有装备判定。玩家快照包含 `utilityCounts`、`helmet`、`defuseKit`、`reserveAmmoAsClips`、`reserveClips`；房间快照包含飞行道具和烟雾状态。闪光事件的 `affected` 列表携带每位受影响玩家的强度和时长，客户端不得给列表外玩家追加致盲。霰弹使用单次 `shot` 事件与 `pellets` 数组。双方移动使用同一个 `weaponSpeedScale()`。

加入房间时提交 `agents: { CT, T }`；更换当前探员发送 `equipAgent` 与目录中的 `agent` ID，由服务器回执并在玩家快照的 `agentId` 中广播。未知 ID、任意资源 URL、跨阵营装备和过快请求会被拒绝。`tests/agents-network.mjs` 覆盖这些边界，以及双客户端同步、重生保留和再次加入时恢复选择。

`tests/equipment-grenades.mjs` 覆盖双 WebSocket 道具购买与投掷广播、全部阵营购买清单、装备经济、护甲保护、拆弹时间、倍率、霰弹与换弹、携带上限、闪光、烟雾、遮挡与碰撞过期。原有输入、跳跃、皮肤同步、死亡重生、异常消息和机器人对局测试继续保留。浏览器实机截图与长时间运行证据见[展示](SHOWCASE.md)和[稳定性说明](STABILITY.md)。
