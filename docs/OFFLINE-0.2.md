# 离线版 0.2.0 · 人机会支援，也会留人守点

这次更新吸收参考 APK 中的出生分散、守点变化、轻松难度和更积极使用道具的思路，按现有离线架构重新实现。下载包仍包含完整资源，Android 与 Windows 均可独立开局。

## 人机调整

- **轻松 / 普通 / 困难三档。** 新增手机入门档，反应较慢、瞄准误差更大；普通与困难保留原有参数，困难反应和精度参数比普通增强约 30%。各档仍通过视线判断和限速转向瞄准，不强制命中。
- **保留原有连败规则。** 普通、困难同队连输 2 回合增强一次 50%，连赢 2 回合恢复；轻松档不触发增强。难度与设置备份兼容。
- **出生分散。** 记录本轮已用出生点，避开活着的队友，避免全队挤到同一个位置。
- **守点轮换。** A/B 各有 8 个候选位置，筛掉无法站立或缺少有效观察角的位置，检查路线后按回合分配。队友优先错开掩体，原有短距离换位、peek 和狙击架点继续使用。
- **有信息才回防。** 附近人机实际听见枪声，或队友目击/阵亡后产生包点报告。枪声默认观察 10 秒，目击报告 3 秒、队友阵亡 5 秒；连续枪声更新情报但不重置等待。最多调动两名人机，保留另一点守备，不把敌人的实时坐标传给回防者。已下包和眼前交战优先处理。
- **道具减少绕路。** 寻找站位的范围扩至 14 米，但同时限制实际路线长度。携包者仅在距投掷位 7 米内、剩余时间充足、附近有持枪队友、尚未到包点时辅助投掷；保护队友阵亡、接敌或准备下包时取消。

## 保留的手机能力

触屏按键位置、大小、透明度与分享码；安装包直接读取本地资源；独立 Worker 中的 30 Hz 对局模拟和 15 Hz 状态同步；默认最低画质与 60 FPS 上限；清晰度、亮度及画幅可调。打开暂停菜单和切后台暂停对局，退出后重新开局。

## 与参考 APK 的取舍

参考来源：[henhaogame/dust2-offline](https://github.com/henhaogame/dust2-offline/tree/9819f6bdcc1343ddf7b65963d290b692275054f2)。实现使用独立源码模块，没有采用构建时覆盖游戏文件的字符串补丁。

本版没有复制真人前三发散布惩罚、共享后坐力状态、全局读取枪声坐标、连败增强关闭、火焰范围与伤害加大、强制单狙或出生点落包规则。已有瞄准、预瞄和投掷轨迹检查继续作为判断依据，避免两套控制器互相覆盖。

“瞄头倾向”是选择瞄准位置的概率，不是实际爆头率。本版不宣传职业选手级胜率或 P60 真机帧率。

## 更新安装

Android 0.2.0 使用与 0.1.0 相同的独立包名和发布证书，版本号递增；可覆盖升级并保留应用设置。更新前可从本地资源页面导出备份。Windows 请将新版 ZIP 解压到新目录，使用同一浏览器与启动地址继续读取设置。

这是离线人机测试版，不能加入在线房间。原在线项目保留在 `main` 分支；线上服务未随本次安装包发布而更新。
