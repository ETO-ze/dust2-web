# 公开地图池

网页入口：<https://cs2.duskrain.cn/>。

公开地图包含 Dust II 与 Mirage。首页默认选择 Dust II；好友分享的地图链接会直接选择相应地图。首页只加载菜单、两张小型预览图和当前地图的房间列表。选择地图不会初始化渲染器或下载地图模型，点击创建或加入房间后才加载所选地图。

地图资源通过现有下载 CDN 获取。通用武器、人物和音频资源沿用根目录的 SHA 缓存，跨地图复用；地图各自的资源清单和内容校验保持独立。返回已经缓存的地图仍需要材质解码、碰撞初始化和显卡准备，缓存不会消除这些步骤。

公共地图页面的根 Service Worker 不截取 `/play/` 请求，因此渲染加载器使用已验证资源的 Blob 映射，避免预下载后再次向游戏服务器读取模型和材质。同目录的旧沙二页面保留原来的 Service Worker 缓存读取行为。

界面小图跟随已验证的 CDN 配置，加载画面的地图配图延迟到开始或加入时设置。首页预缓存不遍历延迟图片属性和原始地图背景目录。地图版本清单、碰撞策略等小文件仍会刷新，以检查资源兼容性。

## 入口和房间

| 地图 | 页面 | 对战连接 |
| --- | --- | --- |
| Dust II | `/play/de_dust2/` | `/play/de_dust2/ws` |
| Mirage | `/play/de_mirage/` | `/play/de_mirage/ws` |

旧沙二 `/ws` 继续有效。Mirage 暂时复用现有服务，限制为一个共享房间，最多十名玩家；私有 Mirage 试玩与公开入口使用同一个房间容量。首页说明该限制并显示现有房间，真人加入时按现有逻辑腾出人机位置。Inferno 尚未公开。

地图切换涉及不同的碰撞数据和权威服务器。进入游戏后改选另一张地图使用新的页面环境，不在正在运行的场景中替换碰撞或把命中判断交给客户端。人机、战术、伤害、经济与回合规则仍由原服务端执行。

## 页面和设置

首页以地图选择和开始对战为主，阵营与开局装备收进可展开区域；设置、装备与房间入口仍可使用。菜单样式限制在首页容器，不改变对局 HUD、加载界面或商店布局。首次点击先解锁音频，再延迟导入游戏模块；手机的自动全屏沿用设置偏好。

现有 APK 和 Windows 安装包继续使用原有入口，本次网页更新不表示这些包已包含 Mirage 的本地素材。需要下载地图的是网页初次进入，后续复用缓存；额外皮肤仍按需获取。

## 部署与回滚

生产更新先校验运行服务、发布目录、配置和归档哈希，再复制不可变资源并切换 HTML；需要调整代理时平滑重载 Nginx，不重启游戏服务。原资源和旧发布包保留，变更前备份，验证失败时回滚。面向实际主机的部署工具、身份清单与诊断记录保存在本地，不随公开源码发布。

Nginx 的地图目录入口用固定上游 `index.html` 响应，避免末尾为 `/` 的单文件 `alias` 触发目录解析。部署就绪检查必须对根首页及两个地图页面分别验证实际 GET 内容和 HEAD 响应，不能仅检查文件存在或 health。

自动测试覆盖地图路径、首页生命周期、音频上下文、房间列表清理、共享缓存、Service Worker 作用域及部署保护。实际浏览器和公开 WSS 的每次验收结果保存在忽略目录 `artifacts/map-pool/`，与自动测试分开记录。手机尺寸模拟不能替代 P60 真机性能验收。

2026-10-04 验证：96 项客户端及相关集成测试、23 项部署测试通过。真实浏览器通过两图进入、沙二移动和开火、米拉吉大资源缓存复用；另有米拉吉九人机和双客户端邀请加入验证。全新浏览器缓存下的首页安装与三种屏幕尺寸检查通过，首页没有提前读取地图素材。
