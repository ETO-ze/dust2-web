日期：2026-09-23。基于离线版 `8dd91e0`，源码分支 `offline-v1`。

## 自动检查与对局

- `node --test --test-concurrency=2 tests/*.mjs`：346 项通过，0 失败。新增用例覆盖轻松档、连败恢复、出生分散、连续枪声不重置回防、听觉范围、守备保留、回合清理、真实地图可站立与可达守点、道具绕路限制、携包者保护条件与精度查询无副作用。
- `node scripts/qa-bot-rework.mjs --output-dir=artifacts/offline-v0.2.0`：3 个固定种子，各 240 秒游戏时间、9 名人机，总计 12 分钟模拟。38 次已验证投掷均达到现有有效落点标准，预测与实际落点最大误差约 0.254 米。观察到推进、peek、回防、下包、拆包、捡枪等行为，玩家位置全部有限。原始记录见 [对局结果](offline-v0.2.0-soak.json)。
- 上述 3 组模拟的逻辑 tick P95 分别为 3.66、3.31、2.75 ms；最大值分别为 64.67、57.75、32.62 ms。仍存在单次尖峰，不能据此宣称没有卡顿。这是桌面 Node 的逻辑耗时，不是手机渲染帧率。
- `node scripts/qa-bot-holding.mjs`：4 种防守阵型各 90 秒模拟，共 6 分钟。20 名人机均有移动，最短累计移动 90 米；每组狙击手实际开镜 36–46 秒。原始记录见 [守点结果](offline-v0.2.0-holding.json)。
- 离线 Vite 构建、Android Release/Debug 构建与 lintRelease 通过。保留大 JS 块和 Android 平台兼容属性警告，没有构建错误。
