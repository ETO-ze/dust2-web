## 从大厅到第一枪

本次发布的新主地址为 **[cs2.duskrain.cn](https://cs2.duskrain.cn/)**，已完成 HTTPS、资源校验、真实浏览器与双客户端联机验收，详细记录在[稳定性说明](docs/STABILITY.md)。游戏支持填写名字后选择 T、CT 或自动平衡，再创建房间。点击「邀请」分享房间链接，朋友可跨网络加入同一场对局；也可以加入机器人独自练习。每个房间最多容纳 10 名玩家，人类加入时机器人会让出位置。

首次进入会下载基础地图、默认探员、动作和声音，并显示真实下载进度。24 套默认武器模型按实际装备加载，额外武器皮肤和可选探员也只在需要时下载。想把基础资源留在本机，可以在大厅打开「本地资源」并点击「保存基础游戏资源」。之后复用缓存，版本更新只补充变化的文件。支持的浏览器还可以将它安装为桌面 PWA。

进入房间先显示 5 对 5 席位，点击「返回游戏」控制角色；打开商店或设置时恢复鼠标。游戏面向支持 **WebGL2 和鼠标锁定的桌面浏览器**，建议使用近期版本的 Chrome 或 Edge。

*房间面板的真实浏览器截图。蓝色为 CT，金色为 T；空位由玩家或房主人机占据。*

### 探员，也可以自己选

在「探员仓库」为两个阵营分别保存外观。默认与可选探员均使用 CS2 原角色模型和骨骼动作，外观会同步给同房玩家；选择不会改变血量、移速或命中判定。

| 阵营 | 默认探员 | 可选探员 |
| --- | --- | --- |
| CT | SAS | 特别探员艾娃 · 联邦调查局（Special Agent Ava） |
| T | 凤凰战士（Phoenix） | 迈阿密达里尔爵士 · 专业人士（Sir Bloody Miami Darryl） |

可选探员按需下载并保存在本机。大厅中可以配置双方外观；对局中更换当前阵营会同步到房间，另一方选择留待下次加入时使用。下载失败可以重试，原有装备仍保留。

高爆手雷最多 1 枚、闪光弹 2 枚、烟雾弹 1 枚，总计最多 4 枚。按住多久都不会提前起爆，引信从出手开始；切换装备、失焦、打开菜单会取消准备动作。烟雾持续 18 秒，以球形区域阻挡机器人视线，并以有限云片呈现；闪光按距离、朝向和墙体遮挡计算。暂未加入燃烧弹、诱饵弹、Source 2 响应式体积烟雾、子弹吹散烟雾与退款。

换边和胜败结算采用原始 CT / T 标志及 Panorama 界面资料重做网页动效；不是直接运行 Source 2 或播放官方结算视频。武器环境光现在跟随地图，野荷等旧皮肤已修正烘焙通道。[界面与动效资料](docs/CS2-UI-SOURCES.md) · [穿透和输入边界](docs/BALLISTICS-AND-INPUT.md)

## 本地运行

需要 **Node.js 22.12 或更新版本**、npm，以及支持 WebGL2 的桌面浏览器。项目源码与大体积运行资源分开管理。

```bash
npm ci
npm run assets:fetch
npm run build
npm start
```

然后打开 **[http://localhost:3000/](http://localhost:3000/)**。`assets:fetch` 为本地服务准备运行资源，并校验文件哈希；服务器持有可选皮肤文件，玩家浏览器仍只在装备时下载。首次准备需要网络和相应素材的使用权限，详见[资源获取与归属说明](docs/ASSETS.md)。

Windows 也可在依赖与资源准备完成后双击 `Start-Game.cmd`。`Stop-Game.cmd` 只停止该启动器记录的本项目进程。改动前端时运行 `npm run dev`，Vite 默认使用 `5178` 端口，将 `/ws` 转发到已启动的本地服务器。

```bash
npm test
```

测试覆盖输入边沿、跳跃与碰撞、武器与购买、双客户端同步、爆破状态、机器人、皮肤和缓存等逻辑。自动化检查不等同于所有设备上的长时间游玩验证。

## 项目结构

```text
client/       Three.js 场景、第一人称武器、HUD、声音、设置与缓存界面
server/       WebSocket 房间、游戏循环、机器人与服务器判定
shared/       双端共用的运动规则、武器、地图数据与 CS 设置换算
public/       静态入口资源、PWA 文件及按清单获取的游戏素材
config/       运行资源文件与校验清单
scripts/      构建、资源准备、本地启动与验证工具
tests/        运动、战斗、联机与界面逻辑回归测试
deploy/       独立目录、systemd 服务与 Nginx 路由部署
docs/         项目实拍、素材说明与展示文案
```

渲染由 **Three.js** 驱动，碰撞使用 **three-mesh-bvh**；客户端进行本地移动预测和远端玩家插值。**Node.js + WebSocket** 负责房间状态，服务器判定移动、弹药、命中、血量、购买与爆破结果。

公网部署需要 HTTPS 和 WebSocket 转发。新主地址使用独立域名根路径，旧站使用 `/dust2/` 路由；游戏目录、服务与网站路由单独管理，凭据不应写进仓库。资源体积较大，下载速度与解码时间也会影响首次进入体验。

## 当前边界

这是一个正在迭代的个人网页 FPS，由独立实现的游戏逻辑驱动，**不是官方 CS2 客户端或 Source 2 引擎移植**。

- 地图保留 CS2 场景几何、原 UV 与纹理；Source 2 的完整烘焙光照、多层材质、皮肤磨损及珠光效果由网页 PBR 近似呈现。
- 第一人称使用 CS2 武器动作与树篱迷宫手套；远端角色可选 SAS、Phoenix、艾娃或迈阿密达里尔的原模型和骨骼动作。网页中的动画混合、持枪对齐、碰撞与烟雾效果仍是独立实现；地图碰撞与导航使用经过对齐的 Awpy 数据。
- 已加入最多 200 毫秒的人物位置回溯与开枪瞬间输入保存；尚未实现官方 sub-tick、竞技反作弊、账号系统、持久战绩和语音聊天。武器与模式规则也没有覆盖 CS2 全部内容，详见[开镜与多人性能修正](docs/SCOPES-AND-PERFORMANCE.md)。
- 已修复角色移除时的 GPU 资源泄漏、音频节点释放问题，以及特定异常网络消息可导致服务端退出的问题。当前构建通过 177 项自动回归。此前 8 机器人浏览器短测运行 204 秒，记录 103 次采样与 29 次死亡，未观察到脚本错误或 WebGL 中断。用户报告的整个浏览器关闭仍未定位，短测不能证明所有设备的长时间稳定性；各版测试分别记录在[稳定性说明](docs/STABILITY.md)。

- [Awpy](https://github.com/pnxenopoulos/awpy)：地图碰撞与导航数据。
- [Quaternius](https://quaternius.com/packs/ultimatemodularcharacters.html)、[Kenney](https://kenney.nl/assets/impact-sounds)：早期版本角色资源、脚步及相关 CC0 素材。
- [Total CS](https://totalcsgo.com/crosshairs/donk) 与 [csgo-sharecode](https://github.com/akiver/csgo-sharecode)：准星比赛记录与分享代码格式参考。
